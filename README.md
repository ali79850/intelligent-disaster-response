# Intelligent Disaster Response & Damage Assessment Platform

> **Status:** Early development (Phase 1 of 14). Not yet functional. This README
> will be filled in progressively as each phase is completed.

## Overview
An AI-assisted platform for analyzing pre- and post-disaster satellite imagery to
produce structured, building-level damage assessments. Built as a research/portfolio
project — **not** a replacement for professional emergency responders or official
disaster assessment authorities.
